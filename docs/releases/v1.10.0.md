# v1.10.0 · Seedream 水印开关：渠道可以关闭「AI 生成」角标

本版处理 [#56](https://github.com/dickpy/dsh-imagegen/issues/56)：火山方舟 / BytePlus 的 Seedream 模型默认会在图片右下角叠加「AI 生成」水印，插件此前没有开关，也从不透传该参数，导致导出的原图必然带角标。

## 主要更新

- **渠道新增「图片添加「AI 生成」水印」开关**（默认开启，保持原有行为）。关闭后，文生图与图生图两条请求都会向上游透传 `watermark: false`，输出不再叠加右下角角标。
- **两处请求体同步透传**：文生图走 `effectiveParams()`，图生图走手工构造的 Seedream 请求体（该分支不展开 `params`），两处都已覆盖，否则会出现"文生图没水印、图生图还有"的半修状态。
- **只对认这个字段的上游发送**：命中官方模型 id（`doubao-seedream-*`）或官方域名（`volces.com` / `bytepluses.com`）才会带上该字段。第三方 OpenAI 兼容中转通常不认识它，避免因此返回 400；同时这也覆盖了插件内置的方舟预置渠道（模型 id 是 `seedream-5.0-pro`，只按名字匹配会漏）。
- **所有入口一致生效**：生图面板、对比生图、无限画布、Agent 工具与 `/edit_image` 命令共用同一个生成运行时，渠道开关对它们同时有效。
- **合规提示写在开关旁**：该角标属于生成合成内容标识，是否关闭由使用者决定，关闭后对外发布时的标注义务同样由使用者承担；上游的隐式水印不受此开关影响。

## 兼容性

- 渠道对象新增可选字段 `watermark`（schema 默认 `true`），旧的设置文档不需要迁移；开关保持开启时，请求体与之前完全一致。
- 未新增运行时依赖，未改动历史、画廊、画布、模板与技能数据。

## 安装

```bash
dsh plugin --profile web add @dickpy/dsh-imagegen@1.10.0
```

从本页的 tgz 附件安装：

```bash
dsh plugin --profile web add <下载路径>/dickpy-dsh-imagegen-1.10.0.tgz
```

## 验证

- 类型检查、构建、单元测试、DOM 端到端与全部 smoke 测试通过。
- 新增 `B7b`：默认不发送 `watermark`；渠道关闭后文生图与图生图请求体都带 `watermark: false`；中转网关（短模型名 + 非官方域名）不会收到该字段。
- 渠道表单新增设置往返断言：关闭开关后 `watermark: false` 会写进设置文档，读取时旧渠道仍视为开启。
- 出图效果未在真实火山方舟账号上实机验证，验收请以关闭开关后原图右下角角标消失为准。
