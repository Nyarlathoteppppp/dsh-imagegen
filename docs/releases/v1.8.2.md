# v1.8.2 · 恢复桌面端插件面板在线更新

- 修复桌面端无条件禁用更新按钮、仅显示“由桌面端管理”的问题。宿主提供插件安装接口时，恢复“在线更新”。
- 使用DSH内置插件管理器安装官方Release的固定版本tgz包，由宿主负责包管理器选择、profile锁和运行时加载；不再对桌面profile运行 `dsh plugin`，也不卸载正在运行的插件。
- 检查宿主返回的安装状态、包名及实际版本；失败、取消、版本不符不会提示成功，原始诊断经脱敏后展示并记录。旧宿主未返回版本时，核对实际profile中的插件清单。
- Web环境没有宿主安装接口时继续使用原CLI更新。只有桌面宿主缺少安装接口时才提示先升级DSH。

## 安装修复包

Web / CLI可将本地tgz路径交给现有 `dsh plugin --profile web add` 命令；桌面端通过宿主支持的插件安装方式导入修复包。

1.8.0/1.8.1面板内的按钮已被旧逻辑禁用，所以第一次需要在插件面板外安装此修复版本，再重启DSH。之后，提供安装接口的桌面宿主可从插件面板在线更新。

本版先提供审核包，打包不代表已经发布npm。真实Electron宿主安装仍需在对应环境验收。
