# v1.8.0 · 模板大抽屉、多图参考与完整预览

## 新功能

- 模板库使用统一悬浮入口和右侧大抽屉，默认约占工作区75%，支持拖宽、记忆宽度及铺满工作区，手机端全宽显示。
- 保留五个模板来源，支持跨库搜索、收藏、最近使用，以及替换或追加提示词。应用模板保留图生图参考图和电商配置。
- 普通图生图支持多选、分批追加、拖拽和粘贴图片，显示64px小缩略图，可删除、清空、点击放大和键盘切换。
- 最多5张参考图，单张不超过10MiB、合计不超过16MiB。图片顺序保持一致；清空后未完成的读取不会重新添加图片。单图请求保持兼容，模型或适配器仅支持单图时会明确提示并阻止多图提交。

## 修复

- 文生图、图生图右侧结果区按可用空间等比完整显示图片，修复大图裁边；保留点击放大。
- 关联 #41：识别宿主profile、桌面启动参数及Windows路径，桌面端停止调用不适用的CLI在线更新，改为明确显示宿主管理指引。
- Web / CLI更新失败时显示实际命令、profile、退出码和经过脱敏的有界日志，并记录到接口诊断。识别pnpm store不匹配，避免只显示“更新失败”；等待输出关闭后再收集错误详情。
- 本版尚未新增桌面宿主的一键更新API，不能将上述修正理解为桌面端已经支持插件自更新。

## 安装与升级

Web / CLI：

```bash
dsh plugin --profile web add @dickpy/dsh-imagegen@1.8.0
```

也可下载本Release的 `dickpy-dsh-imagegen-1.8.0.tgz`，将包名替换为实际tgz路径安装。完成后重启 `dsh web`；若使用自定义profile，请将 `web` 替换为实际名称。

桌面端优先使用DSH桌面应用支持的插件管理流程。若宿主暂无更新入口且需要手动安装：完全退出桌面应用，在实际profile目录检查 `node_modules/.modules.yaml` 的 `packageManager` 和 `storeDir`，使用原来相同版本及store的pnpm安装 `@dickpy/dsh-imagegen@1.8.0`，然后重新启动应用。不要强制切换store或套用Web profile命令。
