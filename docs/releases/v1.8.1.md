# v1.8.1 · 素材库布局修复与生图点阵动画

- 修复素材库排序下拉框占满整行、导致操作栏被挤成多排的问题。排序改用工具栏尺寸，标题与操作区在空间不足时自然换行，窄屏保留所有操作。
- 模板库悬浮按钮改到工作区右侧垂直居中，桌面和手机一致；保留抽屉、拖宽及焦点交互。
- 文生图、图生图生成等待区增加蓝色点阵波纹，展示真实提交/排队/生成状态及耗时，无进度数据时不模拟百分比。支持深色模式和减少动态效果，任务结束后移除动画。
- 仅调整上述界面显示，不改变生成协议、模型适配和图片存储。

## 安装审核包

```bash
dsh plugin --profile web add ./dickpy-dsh-imagegen-1.8.1.tgz
```

安装完成后重启DSH；自定义Web profile请使用实际名称。桌面端使用宿主支持的插件管理流程，或完全退出应用后，在实际profile中使用原pnpm版本与store手动安装审核包。

此版本先打包审核；打包本身不代表已发布npm。
