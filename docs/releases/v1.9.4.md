# v1.9.4 · 会话附件写入与侧栏顶部留白

- 修复生图结果和历史图片加入对话时取不到真实当前会话的问题。优先从宿主会话控制器的最新快照读取当前会话；取不到时展示未预选的会话列表，须用户明确选择后才写入，不会自动挑选历史会话。
- 保留完整附件路径：创建 composer 草稿附件、注册到会话输入、写入服务端会话附件；写入失败时回滚临时草稿附件。
- 生图面板激活时保留宿主侧栏 `topStrip` 顶部占位，避免该占位被插件的侧栏白名单规则隐藏。
- 增加会话附件单元测试与 DOM 端到端回归测试。发布工作流现会在打包前运行这些测试。

验证：类型检查、构建、单元测试、DOM 端到端测试和包 smoke test 通过。未在 DSH Web、Windows Desktop 或 macOS Desktop 宿主中实机验证；本版本不宣称完成这些宿主环境的实机验证。
