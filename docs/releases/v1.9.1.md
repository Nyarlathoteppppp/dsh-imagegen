# v1.9.1 · PPT 转换交付与界面修复（审核包）

- 修复宿主 Agent 的模型/执行错误被「未输出最终 PPTX」掩盖的问题，保留具体错误并脱敏；没有回复时提示检查默认模型连接和工具配置。
- 接收上游 skill 自己 final 目录里的最终 PPTX：只接受完成记录和通过的校验报告，继续检查 PPTX 结构与页数；不把中间页文件作为成功结果。
- 「PPT 配置」改为当前页面直接打开的弹窗，复用生图配置里的同一组字段，不再依赖宿主设置按钮的 DOM 查找。支持 Escape、焦点约束和返回原按钮。
- 上传后移除大上传区域，改为缩略图网格与「＋」卡片，支持点击预览、移动顺序和删除。
- 优化操作区与结果区：桌面端图片列表单独滚动，转换记录用下拉选择，失败提示保留换行并提供复用图片、重新转换、检查配置入口。

- 结果区仅展示最终 PPTX，移除原图、辅助预览图与其他文件卡片；新增 PPT 内容预览和任务诊断入口。预览可查看文字与内嵌图片，复杂版式以 PowerPoint 为准。

本版为审核包，尚未合并或发布 npm。自动回归覆盖宿主错误、脱敏、上游final产物收集、未通过校验的产物拒绝、原有生图功能；浏览器检查缩略图替换上传区、独立配置弹窗、上传排序、取消、下载与不同视口。

截图反馈无法确定用户本机的实际模型/API错误，更新后将显示具体错误；本地未使用用户的真实宿主凭据完成模型转换。
