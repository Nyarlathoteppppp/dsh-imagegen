# v1.8.3 · 补齐多模型对比的生图点阵动画

- 修复文生图、图生图开启多模型对比后没有点阵动画的问题。每个排队或生成中的模型拥有独立动画和状态，耗时从该任务真实时间计算。
- 已完成模型立即显示图片，其他模型继续生成；失败、取消时停止对应动画并保留状态，不遮挡其他已完成图片。
- 修复窄屏多行对比卡片高度被压缩的问题，保证等待点阵有可见区域，较多模型可在对比区内滚动。
- 多模型卡片使用较稀疏的点阵及紧凑状态标识，减少同时动画的圆点数量；支持深色和减少动态效果，不展示虚假百分比。

验证：实际面板回归覆盖文生图、图生图各两个模型的排队、部分完成、生成、失败、取消和全部完成；Chromium验证2/4模型、桌面/手机/短视口及混合状态。
