# v1.9.2 · 会话图片显示与 PPT 消息格式修复

- 修复 #46：会话中的生图工具现在读取 DSH 持久化的结果 metadata，正确显示文生图、图生图及任务查询返回的图片缩略图，并可打开原图。兼容旧会话中的图片内容块与 JSON 引用，重复附件只显示一次。
- 图片仍作为界面展示数据，工具发给模型的内容保持文本，不增加会话消息或强迫文字模型接收图片。
- 修复图片转可编辑 PPT 的 `format v4 message requires a producer-owned source kind`：任务首条消息改用 `plugin:dsh-imagegen`，不再使用被 DSH v4 拒绝的旧 plugin 包装。此修复也适用于无限画布中的重型 skill。
- 保留 1.9.1 的左右布局、多页 PPT 内容预览、下载、配置弹窗和失败诊断。
- 延长 npm 发布后的可见性校验等待时间，避免 npm 后台处理较慢导致流水线过早超时。

验证：类型检查、构建和完整回归；真实会话工具组件的 metadata 图片显示、旧会话回放、去重及无效引用拒绝；DSH 0.2.1-rc.2 官方 v4 codec 实测旧消息拒绝、新消息通过。

上述 PPT 修复针对已确认的消息格式错误；本环境未使用用户的真实模型/API 完成整份 PPT 转换。
