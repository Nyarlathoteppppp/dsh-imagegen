# v1.9.0 · 图片转可编辑 PPT（审核包）

- 新增独立「图片转 PPT」模式：上传 PNG / JPG / WebP，最多12张、每张20MB；缩略图支持排序和删除，一张图片对应一页幻灯片。
- 文生图、图生图结果、多模型对比结果及放大预览新增「生成可编辑 PPT」，点击后直接带入新模式。
- 直接执行 [ningzimu/image-to-editable-ppt-skill](https://github.com/ningzimu/image-to-editable-ppt-skill)；复用现有 DSH 技能 Agent，不自行实现图片重建流程。
- 生图配置新增 PPT 专区：安装/更新官方 skill，安装/检查隔离的 editppt Python 环境，配置图像 API 与 PaddleOCR token；密钥沿用 secret 存储，不进入任务提示词。
- 可选择 PaddleOCR 或本次离线文字检测；转换显示真实状态，支持取消、结果下载及复用输入；记录与产物保存在宿主侧。
- 没有最终 PPTX、无效 ZIP、页数不符均报失败；宿主重启后的未完成任务显示中断，可再次转换。

前提：Python 3.10+；DSH 已配置默认模型，并启用技能和长任务，Agent 预设提供文件/命令工具。多页转换按上游 skill 使用页任务，需要预设支持子 Agent。PaddleOCR token 可选；图像后端需要有效 Codex OAuth 或兼容图像 API。

当前为本地审核版本，尚未合并 main 或发布 npm。自动回归替代模型调用；上游 CLI 的安装、doctor、prepare、离线 hints 已实测。尚未在用户桌面端使用真实付费模型完成整份转换，需要安装审核包后验证还原质量。
